## Findings & Ideas to Improve Portfolio Performance

**`s15` LIMIT-3% @5% wins both rankings** — Calmar 1.832 AND Final$ $301,361 (CAGR +42.7%, MaxDD -23.3%, Sortino 1.391). The same configuration family also won the 2010-2026 full-cycle run (there at 4-5% sizing), so this is not a window artifact: s15 + 3%-discount resting limit + ~5% position size is the most robust setup across both regimes tested.

**s20's small-size EOD edge persists but only exactly there.** `s20` EOD @3% is a photo-finish #2 by Calmar (1.831) — at minimum size, taking the tightest signals immediately at the close is competitive. But it degrades quickly with size (0.9-1.0 at 5-8%) because ~5 signals/month can't fill a bigger book: Uninv% 24.9% at 3% sizing vs s15's 11-15%.

**The limit-order pattern replicates the full-cycle result exactly**: LIMIT-3% wins for `s15` at every size (Calmar 1.832 vs 1.113 at 5%; Final$ +74%) and for `s12` at every size except 8% (s12@3%: Final $125,353 → $221,693, +77%), while for `s20` it's mixed and turns negative at 5-8%. The mechanism is the same as documented in the full-cycle findings: the discount compounds hardest where signal flow is high enough to replace the fills that never pull back.

**Window comparison (identical methodology, adjusted prices)**: 2020-2026 metrics run ~2.3x the 2010-2026 full cycle — best Calmar 1.832 vs 0.786, best CAGR +42.7% vs +25.8%. With the methodology now fixed in both runs, this is a clean regime measurement: treat this window as the favorable-regime ceiling and the full-cycle numbers as the base case. (The 2026-07-12 version of this doc used the old tr20/vdu80 algorithm AND raw un-adjusted prices, so its numbers are not comparable to either run.)

**Ideas to improve Mean%/Sortino/Calmar** (unchanged from the full-cycle run, all still open):
1. **Rank-based funding** — `s12` skips ~1,700 signals for lack of cash even in this short window; funding by ADR%/breakout quality instead of arrival order is the biggest untested lever (`RANK_FUNDING` infra exists).
2. **Early-exit sweep** (`sma200x3`/`trail25`, already implemented) targeted at the large-size configs where MaxDD reaches -35 to -49%.
3. **Blend s20-priority + s15-fill** (`run_blend`, implemented but unused) to combine s20's per-trade quality with s15's capital utilization.
4. **cd15/p3 relaxations at portfolio level** — more flow should help the high-skip configs the way vdu90's extra signals helped s20's utilization here.
